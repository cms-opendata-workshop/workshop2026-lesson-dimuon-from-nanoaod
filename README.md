## What is this?
In this notebook you will learn how to fetch data from the CERN Open Data Portal (two-muon events), read it in, calculate invariant mass, and make plots.

- Intended audience
  - High school or university physics students
- Learning goals
  - How to load NANOAOD using awkward
  - How to make simple selections on events
  - How to calculate and plot invariant mass
- Necessary skills/background knowledge
  - Python in a jupyter environment
  - awkward arrays
  - Python plotting with matplotlib
  - invariant mass
- Length of time to complete
  - 20 mins
